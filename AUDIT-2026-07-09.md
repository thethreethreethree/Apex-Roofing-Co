## Findings & resolutions

- **H1 (HIGH) — `PAYLOAD_SECRET` defaulted to `''`.** An empty secret signs forgeable
  admin sessions. **Fixed:** fail-fast `throw` when `NODE_ENV=production` and the secret
  is unset; dev keeps a fixed fallback. *Verified:* prod+no-secret throws the exact
  message; prod+secret loads; dev+no-secret loads.
- **M1 (MED) — no rate limit on public forms.** Honeypot stops dumb bots only. **Fixed:**
  per-IP fixed-window limiter (`src/lib/ratelimit.ts`), 5/min on `submitLead` and
  `createBooking`, keyed off `x-forwarded-for`. *Verified:* unit test (5 pass, 6th blocked,
  separate key independent). *Untested:* real multi-IP HTTP behavior behind Caddy.
- **M2 (MED) — no security headers.** **Fixed:** `X-Content-Type-Options: nosniff`,
  `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy`, `X-DNS-Prefetch-Control` for all routes
  (no strict CSP — the Payload admin needs inline scripts). *Verified:* headers served on `/`.
- **L1 (LOW) — `robots`/`sitemap` fall back to `http://localhost:3000`** when
  `NEXT_PUBLIC_SITE_URL` is unset. **Not changed:** `DEPLOY.md` sets the env var; behavior is
  correct once set. Left as a documented flag rather than adding indirection.

## Later finding — color contrast (WCAG)
- **A11y-contrast (MED–HIGH) — accent fails WCAG AA.** Computed ratios: brand `#1c5f6b`
  on white **7.24 (PASS)**; **accent `#f2994a` on white 2.23 (FAIL)**; **white on accent
  2.23 (FAIL)**. This hits the **primary CTA buttons** (white text on amber) and accent
  text (prices, "Learn more"). AA needs 4.5:1 (3:1 for large text).
  **Not auto-fixed** — the accent is a brand/design choice and the owner is reviewing the
  current look. Recommended fix: darken Branding → accent to **`#b45309`** (white-on-accent
  **5.02**, AA pass), still amber-family; one field in Admin → Branding re-themes the site.
  Flagged in LAUNCH-CHECKLIST for the owner's decision.
